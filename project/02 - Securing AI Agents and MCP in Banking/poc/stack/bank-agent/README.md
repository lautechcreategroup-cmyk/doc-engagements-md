# Bank agent

The bank's enterprise agent (Z3). One validated intent in, one schema-shaped answer out; fresh context per
request; tools from the Banking MCP only; no other network route except the model API. Exact arithmetic in Python
helpers; the model plans, picks tools and explains. Includes a CLI harness (`make ask …`) for testing without the
edge. See [architecture.md](../../architecture.md) and the build prompt.
